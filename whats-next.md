You may not be familiar with emulating the classic Mac OS, or with the classic Mac OS to begin with. I've pulled together some resources here that can answer your questions, so I don't have to reinvent the wheel.

If you want to try experimenting with custom display resolutions (so you can get the viewable image of the Waveshare screen to fit within a bezel), this project looks like it can help: https://github.com/spc6486/display-calibrator

The [E-maculation Wiki](https://www.emaculation.com/doku.php) is probably the definitive resource on Mac emulation. It has how-to articles not just about Mini vMac, but a number of other emulators, along with general information about working with disk images.

A useful tool when trying to move disk images between physical classic Macs and emulators is [Disk Jockey](https://diskjockey.onegeekarmy.eu).

The BlueSCSI documentation also has useful pages about [disk images](https://bluescsi.com/docs/BlueSCSI-Images) and [emulation](https://bluescsi.com/docs/Emulators), since it's often more convenient to set up an installation in an emulator, then transfer it to a real Mac.

[Infinite Mac](https://infinitemac.org) is an incredible Mac emulator that runs inside your browser, and is gaining new features constantly.

And of course, the go-to for vintage Mac software downloads is [the Macintosh Garden](https://www.macintoshgarden.org).
